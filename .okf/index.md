# ext-gstreamer

1:1 PHP bindings of GStreamer's gstreamer, gstreamer-app, gstreamer-video, gstreamer-audio and gstreamer-pbutils. Version 0.11.0. Linux and macOS. The floor is GStreamer 1.26.2. Scope: functional parity with ext-ffmpeg (the decode path).
