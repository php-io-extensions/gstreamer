# Agent guidance — php-io-extensions/gstreamer

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches. The design and its decisions are in [`docs/superpowers/specs/2026-11-11-gstreamer-design.md`](docs/superpowers/specs/2026-11-11-gstreamer-design.md).
2. **Bindings are 1:1 at GStreamer's C API.** Function and constant names are the C names. No defaults, no composites, no helpers. The floor is GStreamer 1.26.2 (Debian trixie); Homebrew builds against a newer GStreamer. Bind a function or constant only when the 1.26 headers declare it (`scripts/support.php` counts them). Scope is functional parity with ext-ffmpeg: decode path only, every call on the PHP thread (pull-mode appsink, `gst_bus_timed_pop_filtered`), no signals or streaming-thread callbacks.
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   Kept: `gst-field-released`, in `gstreamer_field` (`src/fields.c`). Kept refusals carry `/* binding:<id> */`, read `if (!GSTREAMER_PROBE_OFF("<id>") && (<check>))`, have a `sites` entry in `bindings.json` and a probe in `tests/Probes` (`gstreamerProbe()` in `tests/Pest.php`). The probe file is committed before the `sites` entry. Probe builds use `GSTREAMER_CONFIGURE=--enable-gstreamer-probes`. Never ship a probe build. Translation: a GError a call reported is thrown as `GstError` after the call (`gstreamer_throw_gerror`).
4. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the GStreamer headers pkg-config gives for `config.m4`'s modules; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` (`gstreamer_gobject_arg`) or `helpers.translate` (`gstreamer_throw_gerror`) function. A `PHP_FUNCTION` must be written out, not made by a macro: the pre-commit hook matches each one to its stub. Extension files are edited with the Edit/Write tools; shell writes into the repo are blocked.
5. **Handles.** Private `__construct`, not cloneable, not serializable, `pointer(): int`, `static fromPointer(int $pointer): ?static`. One PHP object per native pointer (`gstreamer_box`); a GObject gets the most derived bound class its GType is (`gstreamer_box_gobject`). `fromPointer(0)` is `null`; any other address is trusted. Dropping the PHP object does not unref. The binding counts the references it has seen; the unref that brings them to 0 releases the handle (pointer 0). `gst_bin_add` of a floating element hands it to the bin (`gstreamer_disown`). No `GObject` and no `GError` class: ext-gtk owns those PHP names. `GstObject` and the discoverer types are top classes; `GObject *` / `gpointer` parameters take any of them (`typemap`).
6. **Fields.** A getter is named as the C field, listed under `glue` in `bindings.json`, and added to the table in `src/fields.c`. Every getter's method entry is `gstreamer_field`: the module's C file maps `zim_<Class>_<field>` to it before it includes the arginfo.
7. **The stub is the declaration.** One stub per module in `stubs/` (`gst`, `app`, `video`, `audio`, `pbutils`), registered from the C file of the same name. Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, and commit both. Never hand-edit `*_arginfo.h`. A constant's docblock is `/** @var int` and ` * @cvalue NAME */` on two lines. gen_stub rejects `@param` lines with generic types: describe such a parameter in the summary.
8. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts` (Homebrew `gstreamer` only; the script refuses another one); `./install-debian-trixie.sh` on Debian and the Pi. Pest at `-d memory_limit=128M` on both builds. Tests need a temporary `composer install`; remove `vendor/` and `composer.lock` after. Gate a commit on the suite's exit code. Media for tests are made by GStreamer in the test (`wavFixture()`, a `videotestsrc ! jpegenc ! avimux` file): no fixture files. Output goes to `appsink`, `fakesink` or `filesink` only: no sound, no window.
9. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`. Run `php84 scripts/support.php` after a stub change.
10. **Version** is `PHP_GSTREAMER_VERSION` in `php_gstreamer.h`: 0.11.0. `os-families`: linux, darwin.
